# 00 · 术语表（Glossary）

> 所有 Spec、代码、内容资产的**唯一术语标准**。任何文档/代码中出现与下表不一致的叫法，以本表为准。
> 代码标识符统一使用英文 key，文案展示统一使用中文名。

## 1. 产品与品牌

| 术语 | 英文/代码 key | 定义 |
|------|--------------|------|
| CBTI | `CBTI` | Character-Based Type Indicator，角色人格指标 |
| 灵魂数据指纹 | `soul fingerprint` | 用户答题后生成的 5 维数据画像 |
| 模式串 | `pattern` | 5 位档位串，形如 `H-H-M-L-H`，维度顺序固定（见下） |
| 灵魂原型 | `archetype` | 28 组角色的抽象分类名（如"逆袭枭雄"） |
| 灵魂近亲 | `relative` | 匹配距离第二小的角色 |
| 隐藏角色 | `easter character` | 魔童哪吒(#27) / 黑神话悟空(#28)，彩蛋触发锁定 |
| 彩蛋种子题 | `easter question` | 题 14/15，选项带隐藏标记 |
| 彩蛋种子选项 | `seed option` | 带 `seedTag` 的选项 |

## 2. 五维模型

**维度顺序固定不变**，模式串、数组、雷达图全部按此顺序：

| # | 中文名 | 量词名 | 代码 key | 雷达图位置 |
|---|--------|--------|----------|-----------|
| 1 | 存在感 | 锋芒度 | `presence` | 正上方（-90°） |
| 2 | 认知力 | 执棋力 | `cognition` | 右上（-18°） |
| 3 | 情感力 | 情感值 | `emotion` | 右下（54°） |
| 4 | 规则感 | 秩序感 | `order` | 左下（126°） |
| 5 | 持久力 | 坚韧值 | `endurance` | 左上（162°） |

（角度沿顺时针方向，即 `-90° + 72° × i`。）

## 3. 档位与计分

| 术语 | 代码 | 定义 |
|------|------|------|
| 选项档位 | `OptionBand` = `L / M1 / M2 / H` | 每题 4 个选项各占一档 |
| 最终档位 | `FinalBand` = `L / M / H` | M1/M2 在匹配时统一归入 M |
| 选项分值 | `OPTION_SCORE` | L=2，M1=4，M2=6，H=9（固定值，见 specs/30） |
| 维度均分 | `dimensionScore` | 该维度 3 题得分的算术平均，1.0–10.0 |
| 角色锚点值 | `CHARACTER_ANCHOR` | 雷达图角色线取值：L=2，M=5，H=9 |

## 4. 匹配池

| 术语 | 代码 | 定义 |
|------|------|------|
| 男性角色池 | `pool: 'male'` | 性别分流后进入，含男角色 + 通用角色 |
| 女性角色池 | `pool: 'female'` | 同上，含女角色 + 通用角色 |
| 通用角色 | `gender: 'universal'` | #27/#28，两个池都可匹配 |
| 性别分流题 | `gender-split question` | 题 1，选项的 `targetPool` 决定进池 |

## 5. 内容资产

| 术语 | 定义 |
|------|------|
| 经典梗台词 `quote` | 角色最有辨识度的一句台词/梗 |
| 灵魂标签 `tags` | 3–5 个 `#` 标签 |
| 扎心解读 `interpretation` | 3–5 段结果页文案（SBTI 风格） |
| 现代平行宇宙 `parallelUniverse` | 角色穿越到现代的一段设定文案 |
| 二创立绘 `illustration` | 傻雕漫画风格的角色插画 |

## 6. 工程术语

| 术语 | 定义 |
|------|------|
| Spec | `specs/` 下的需求/规范文件，代码的唯一依据 |
| Task | `tasks/` 下拆出的原子任务，派发给 AI Agent 执行 |
| 主链路 | `tasks/v1.0-tasks.md` 中的工程任务序列 |
| 内容管线 | `tasks/content-tasks.md` 中的内容生产任务序列，主链路完成后启动 |
| H5 | UniApp 编译的 Web 端（纯 CSR，无 SSR/SSG） |
| MP | 微信小程序端（mp-weixin） |
