# 00 · 术语表（Glossary）

> 所有 Spec、代码、内容资产的**唯一术语标准**。任何文档/代码中出现与下表不一致的叫法，以本表为准。
> 代码标识符统一使用英文 key，文案展示统一使用中文名。
> 本表随 CBTI v4.0 题库（题材分流六版）同步升级；v3.0 的旧选项档位与性别分流概念已废弃，不再使用。

## 1. 产品与品牌

| 术语 | 英文/代码 key | 定义 |
|------|--------------|------|
| CBTI | `CBTI` | Character-Based Type Indicator，角色人格指标 |
| 灵魂数据指纹 | `soul fingerprint` | 用户答题后生成的 5 维数据画像 |
| 模式串 | `pattern` | 5 位档位串，形如 `H-H-M-L-H`，维度顺序固定（见下） |
| 灵魂原型 | `archetype` | 角色原型编号 1–30 的抽象分类名（如"逆袭枭雄"） |
| 灵魂近亲 | `relative` | 池内除主结果外，模式串距离用户最近的角色 |
| 隐藏角色 | `easter character` | 魔童哪吒(#27) / 黑神话悟空(#28) / 精卫(#29) / 女娲(#30)，彩蛋触发锁定 |
| 彩蛋种子题 | `easter question` | 类别题库第 7 题 / 第 11 题，选项带隐藏标记 |
| 彩蛋种子选项 | `seed option` | 带 `seedTag` 的选项 |
| 彩蛋种子 | `SeedTag` | `nezha` / `wukong` / `jingwei` / `nuwa`，两题同选同一种子才锁定 |

## 2. 五维模型

**维度顺序固定不变**，模式串、数组、雷达图全部按此顺序：

| # | 中文名 | 量词名 | 代码 key | 雷达图位置 |
|---|--------|--------|----------|-----------|
| 1 | 存在感 | 锋芒度 | `presence` | 正上方（-90°） |
| 2 | 认知力 | 执棋力 | `cognition` | 右上（-18°） |
| 3 | 情感力 | 情感值 | `emotion` | 右下（54°） |
| 4 | 规则感 | 秩序感 | `order` | 左下（126°） |
| 5 | 持久力 | 坚韧值 | `endurance` | 左上（162°） |

（角度沿顺时针方向，即 `-90° + 72° × i`。）

## 3. 计分模型

| 术语 | 代码 | 定义 |
|------|------|------|
| 维度对 | `pair` | 计分题的数据结构 `[Dimension, Dimension]`：第一位取网格 X 值 `{1,5,10}`，第二位取 Y 值 `{2,9}` |
| 3×2 网格 | `GRID` | 6 个固定分值位：`(1,2) (1,9) (5,2) (5,9) (10,2) (10,9)`，对应每题 6 选项 |
| 最终档位 | `FinalBand` = `L / M / H` | 由每维原始总分对照分维阈值得到 |
| 分维阈值 | `DIMENSION_THRESHOLDS` | 5 个维度各自的 L/M/H 总分切点，唯一定义见 specs/30 §3 |
| 维度原始总分 | `dimensionTotal` | 该维度在 15 道计分题中出现的 6 次分值累加；各维最小/最大范围见 specs/30 §2 |
| 用户归一化值 | `dimensionScore` | 维度原始总分按各维 MIN/MAX 线性归一化到 1.0–10.0，保留 2 位小数，雷达图用户线用 |
| 角色锚点值 | `CHARACTER_ANCHOR` | 雷达图角色线取值：L=2，M=5，H=9 |

## 4. 题材与匹配池

| 术语 | 代码 | 定义 |
|------|------|------|
| 题材 | `Category` | 6 个题材入口：`xiuxian` / `jianghu` / `rexue` / `mori` / `gongting` / `dushi` |
| 题材中文名 | — | 修仙宗门 / 江湖朝堂 / 热血校园竞技 / 末日求生 / 宫廷深宅后宫 / 都市闺蜜职场 |
| 题材分流题 | `theme-split question` | 第一屏的 6 选项世界入口，选项带 `targetCategory`；**不计分** |
| 池映射 | `CATEGORY_POOL` | 修仙/江湖/热血 → `male`；末日/宫廷/都市 → `female` |
| 男性角色池 | `pool: 'male'` | 原型 1–26 的 male 版 + #27 哪吒 + #28 悟空 |
| 女性角色池 | `pool: 'female'` | 原型 1–26 的 female 版 + #29 精卫 + #30 女娲 |
| 均衡查找表 | `LUT` | `scripts/build-match-table.py` 生成的 243 格 → 角色 id 映射，每池一份；生成产物 `match-lut.ts` 禁止手改 |
