# 50-pages/loading · 加载页规范

> 路由：`pages/loading/index`。目标：2–3 秒仪式感，掩护结果计算与结果页预热。

## 1. 行为

- 进入即开始打字机轮播以下文案（每句 40ms/字，句间停顿 400ms，整体 2.2–3s）：
  1. 「正在调取你的互联网病历…」
  2. 「正在扫描你的灵魂五维…」
  3. 「正在匹配你的灵魂住客…」
- 彩蛋锁定（nezha/wukong/jingwei/nuwa 任一触发）时，第三句替换为「检测到异常灵魂波动…？」（用户不知彩蛋，纯悬念）。
- 文案播完且 `store.result` 就绪 → `uni.redirectTo` 结果页。

## 2. 视觉

- 居中灵魂扫描动画：一个 ink 描边的圆，内部用 CSS 画正弦波/扫描线循环（纯 CSS，禁 GIF）。
- 背景 `--cbti-paper`，文案 H2。

## 3. 验收标准

- [ ] 总时长 2.2–3s，不可跳过也不可停滞
- [ ] `result` 未就绪时循环播放等待（兜底 5s 超时强制跳转，见 specs/92）
- [ ] 彩蛋文案替换逻辑有单测覆盖（core 层判定，页面只读 `easterLocked`）
