# 50-pages/home · 首页规范

> 路由：`pages/home/index`。目标：3 秒内让用户点下「开始测试」。

## 1. 页面区块（自上而下）

| # | 区块 | 内容 | 备注 |
|---|------|------|------|
| 1 | 品牌区 | 大字 `CBTI` + 全称「Character-Based Type Indicator」+ Slogan「测测你的灵魂被哪个角色附体了」+ 副标题「你的脑子里，住着谁？」 | 文案见 PRD §二 |
| 2 | 角色轮播 | 热门角色贴纸卡横向轮播（≥6 张），16personalities 式结构：立绘大卡 + 灵魂原型名 + 角色名·出处 + 一句简介 brief + 台词气泡（quote/quoteExtra） | 结构契约见 specs/45 §5；自动播放 3s/张，可手动滑动；立绘缺失时首字符占位不裂图 |
| 3 | 开始按钮 | 「开始测试」主按钮（灵魂紫，贴纸风） | 点击 → 初始化 store → 跳转答题页 |
| 4 | 底部说明 | 「15 道题 · 约 2 分钟 · 仅供娱乐」 | caption 级 |

**MVP 明确砍掉**：「已有 XX 万人测过」计数器（零后端原则，不做假数字）。

## 2. 交互与状态

- 进入首页时若 store 中有未完成答题进度 → 按钮文案变为「继续上次测试」，副入口「重新开始」。
- 所有跳转用 `uni.navigateTo`。

## 3. 验收标准

- [ ] 首屏无接口请求，秒开
- [ ] 轮播可自动/手动，立绘缺失时有占位不裂图
- [ ] 按钮按压态符合 specs/40 §4 贴纸反馈
- [ ] H5 与 MP 视觉一致
