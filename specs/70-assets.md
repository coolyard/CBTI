# 70 · 视觉资产规范（二创立绘）

> 全部立绘为**离线预生成**静态资产，运行时零 AI 调用。风格：**傻雕漫画 / 搞笑**。

## 1. 风格圣经（Style Bible）

**统一风格前缀**（每个 Prompt 开头必须原样带上，保证 54 张图风格一致）：

```
傻雕四格漫画风格, Q版三头身, 夸张表情包式五官, 粗黑描边, 高饱和纯色平涂,
贴纸质感, 白色或高饱和纯色背景, 居中半身像, 正面朝向, 画风搞笑接地气,
类似微信爆款表情包, 无真人五官, 无写实细节
```

**统一反面约束**：

```
真人照片感, 写实油画, 日漫美型, 复杂背景, 水印, 文字乱码, 多人同框
```

**角色专属部分**（每人 1–2 句）：身份符号 + 一个标志性道具/动作。
⚠️ 版权边界：描述**角色气质与符号**（如「卖鱼起家的黑帮老大气质」），不要求长得像具体演员；神似不照搬，这是二创安全线。

## 2. 台词入图策略（二选一，推荐 A）

| 方案 | 做法 | 取舍 |
|------|------|------|
| **A. 图文分离（推荐）** | AI 只生成纯净立绘；quote 在结果页/海报用代码渲染（Canvas 台词气泡已实现） | 文字零乱码、可改文案不重画图、海报排版统一 |
| B. 图内生字 | Prompt 末尾加「头顶漫画对话框，内写中文『{quote}』」 | 中文渲染不稳，仅即梦可用；写错字需重抽 |

## 3. 推荐 AI 生图工具

| 工具 | 优势 | 注意 |
|------|------|------|
| **豆包（doubao.com，字节 Seedream）** | 免费、原图 2048×2048 富余量大（压至 640×640 达标）；与即梦同模型系，中文 Prompt 理解一致 | 输出带「豆包AI生成」浅色水印（合规保留，见 §5 注）；每日免费额度约 10–30 张（随平台策略浮动），54 张分批 2–5 天出完 |
| **即梦 AI（字节）** | 中文 Prompt 理解好；中文文字渲染最强（方案 B 唯一可选）；表情包风格多 | 免费版每日 60–100 积分（≈20–30 张）且**带平台水印**（与 §6 验收冲突，入库时需裁剪规避）；会员 ¥79/月（连续包月 ¥41）去水印 |
| 可灵 / 通义万相 | 备选，风格库接近 | 免费额度同为积分日限制 |
| Midjourney | 风格天花板 | 中文文字基本不可用；与本项目中文语境不匹配 |

> 价格与额度为 2026-08 核实的公开口径，各平台年内多次调价，执行 C06-A 前以官网实时为准。

**建议工作流**：用豆包（或即梦会员）按 §4 模板批量出图（每角色抽 2–3 张）→ 人工筛 1 张 → 统一压缩。

## 4. 立绘 Prompt 模板

```
{风格前缀},
角色：{角色名}的灵魂气质 —— {身份符号 1 句}, {标志性道具/动作 1 句},
表情：{夸张表情描述},
{方案 B 才加：台词气泡}
```

**示例（3 个，全套 54 个由内容管线批量产出）：**

1. **高启强**：`{风格前缀}, 角色：中年鱼贩逆袭成黑帮大佬的气质 —— 穿旧夹克端着一盘鱼, 一手叉腰一手指天, 表情：眯眼坏笑胸有成竹`
2. **甄嬛**：`{风格前缀}, 角色：深宫娘娘成长为大女主的气质 —— 清宫旗头抱着一只猫, 指尖捏着一朵杏花, 表情：皮笑肉不笑眼神看穿一切`
3. **魔童哪吒**：`{风格前缀}, 角色：混世魔童的气质 —— 扎两个冲天鬏踩着风火轮, 双手插兜吊儿郎当, 表情：歪嘴狂笑一脸不服`

## 5. 资产规格

| 项 | 规范 |
|----|------|
| 尺寸 | 640×640（1:1） |
| 格式 | WebP，单张 ≤ 200KB |
| 命名 | `char-{id}-{gender}.webp`，如 `char-01-male.webp`；通用角色 `char-27-universal.webp` |
| 存放 | 唯一存放 `src/pkg-characters/characters/`：MP 走分包；H5 build 由 vite `copyPkgAssets` 插件拷入产物，H5 dev 由 vite dev 中间件服务。**禁止放 `src/static/`**（会被 MP 打进主包，挤爆主包 2MB 预算） |
| 缺失降级 | 首字符圆形占位图（轮换底色，specs/40 §2） |
| 头部立绘（圆形头像框专用） | 独立分包 `src/pkg-heads/heads/`；320×320 WebP，单张 ≤60KB、总量 ≤800KB；命名 `head-{原型两位补零}-{male|female|universal}.webp`；由 `scripts/make-headshots.py` 从 640 立绘裁切（`CROP_SIDE=0.60`、`CROP_TOP=0.02`），裁切参数变更需重跑脚本 |
| 装饰贴纸（可选 AI 增强包） | `src/static/decor/`，透明底 WebP 320×320 ≤60KB，总量 ≤300KB；默认用 CSS/emoji 装饰（specs/45 §8），贴纸包就绪后替换 |

> 注 1（为何是 640）：微信单分包上限 2MB（specs/80 §3），54 张 1024×1024 WebP 实测总计约 3.9MB 超限；640×640 在 q=80 下实测 1874KB（1.83MB）可整体入单分包（压缩脚本内置总量预算 1900KB，质量自动降档兜底）。使用侧最大渲染需求为海报立绘圆（半径 110px，3x 屏等效 660px），640 刚好覆盖。
> 注 2（水印）：豆包出图自带「豆包AI生成」浅色水印，按 AI 生成内容标识合规要求**保留**，不裁剪、不抹除；结果页/海报均为圆形裁剪展示，角落水印自然弱化。

## 6. 入库验收

- [ ] 54 张图风格并排看不出违和（同一风格前缀的约束力）
- [ ] 无真人脸、无乱码文字（方案 A）；仅允许豆包「AI生成」浅色水印（§5 注 2，合规保留）
- [ ] 每张 ≤ 200KB，命名通过 `npm run test` 中的资产清单校验
