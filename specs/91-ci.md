# 91 · CI 规范

> 平台：GitHub Actions，工作流文件 `.github/workflows/ci.yml`（已入库，与本文件同步维护）。

## 1. 触发与流水线

- 触发：`push` 到 `main`、所有 Pull Request。
- 环境：`ubuntu-latest`，Node 20，pnpm（`pnpm/action-setup` + 缓存）。
- 步骤（任一失败即红）：
  1. `pnpm install --frozen-lockfile`
  2. `pnpm lint`
  3. `pnpm typecheck`
  4. `pnpm test`
  5. `pnpm build:h5`
  6. `pnpm build:mp-weixin`

## 2. 约定

- 构建产物（`dist/`）作为 workflow artifact 上传保留 7 天，便于验收。
- 不在 CI 里做任何发布动作；发布是人工操作（见 specs/80 §5）。
- CI 配置变更必须同 PR 说明理由；禁止给 CI 加「允许失败」的步骤。

## 3. 本地对齐

提交前本地执行与 CI 完全相同的命令序列（specs/10 §5），保证「本地绿 = CI 绿」。
